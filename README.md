## ⚡ Tech Stack & Architecture

- **Core & Framework**: React 19, Vite, JavaScript (ES modules)
- **3D & Creative Canvas**: Three.js, `@react-three/fiber`, `@react-three/drei` (Interactive real-time 3D Neural Wave & Particle Constellation)
- **Styling & Tokens**: Custom Tailwind CSS design tokens, Glassmorphism, Warm Golden Amber (`#FFC700`) & Deep Obsidian (`#08080A`) visual identity
- **Motion & Interaction**: Framer Motion, Canvas Confetti, Web Audio API sound synthesizers
- **Icons & Typography**: Lucide React, Google Fonts (`Outfit`, `Plus Jakarta Sans`, `JetBrains Mono`)
- **Deployment & CI/CD**: GitHub Actions, GitHub Pages

## 🛠️ Local Development

### Prerequisites
- Node.js 18+ or 20+
- npm (bundled with Node.js)

### Setup & Run
```bash
# Clone the repository
git clone https://github.com/omkar-nath-rdy/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start local development server (with HMR)
npm run dev
```

Visit `http://localhost:3000` to explore the live development server.

### Production Build
```bash
# Build optimized production assets to dist/
npm run build

# Preview production build locally
npm run preview
```

---

## 🚢 Deployment to GitHub Pages

This repository is pre-configured with **GitHub Actions** for automatic zero-downtime deployment on every push to `main`.

1. Go to repository **Settings** > **Pages**.
2. Under **Build and deployment** > **Source**, select **GitHub Actions**.
3. Push changes to `main` — GitHub will automatically build and publish the live site!
